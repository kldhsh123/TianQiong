---

天穹语言，应数字文明之运而生。承上古开天之志，立当代编程之基，
以「混沌」辟程序之源，以「盘古」启运行之门，阴阳相济而万物生，
乾坤一体而全域通。天穹者，非徒一语言也，实乃面向未来十年之
**自主创新基础软件生态基座**。

## 快速上手

获取「天穹独行之器」（exe），置于 PATH，而后：

```
天穹 传火 我的项目        :: 起新项，传火于后世
天穹 运行 我的项目.天穹     :: 执行
天穹 问道                 :: 交互问道之境
```

### 数术

中缀之算，合乎自然：`加 减 乘 除以 整除 余 幂`，
比较曰 `大于 小于 等于`，逻辑曰 `且 或 非`，
另有管道之便：`"天穹" | 长度`。

### 律令

```
造化 菲波 以 数
    若 数 小于 2
        归一 数
    否则
        归一 菲波(数 减 1) 加 菲波(数 减 2)

遍历 甲 于 范围(0, 10)
    阳 菲波 甲 存于 果
```

## 错误公文体系

天穹之失，皆行公文，格式统一，级别分明：

```
天穹编译错误：
语义未定义
  于「我的项目.天穹」第 5 行
  天地间未闻此名「名稱」
```

提示 < 警示 < 错误 < 阴阳冲突，四级定分，一目了然。
